## Сделано после исключений: `RARUS_HOME`
Коммит `d4fb082`. Переменная `RARUS_HOME` вместо `RAVEN_HOME`, каталог по умолчанию `~/.rarus` вместо `~/.raven` — в коде, тестах, документах, схеме RPC и исходниках интерфейса. Жёстко прописанные `Path.home() / ".raven"` (браузерный профиль, кэши маршрутизации, кэш хаба навыков, WhatsApp-мост, пароль входа в оболочку) переведены на новое имя. Из-за изменения константы в контрактном слое `CONTRACTS_VERSION` стал 37, отпечаток поверхности перепривязан. Каталоги внутри проекта пользователя (`.raven/plans`, `.raven/shadow.git`, `.raven/plugins`) оставлены до прохода по брендингу.

Проверка: полный прогон против нетронутой копии Raven — 940 падений против 967, новых нет (четыре, возникшие после переименования, исправлены: отпечаток контрактов, два теста про каталог проекта, список «своих» каталогов проверки навыков).
