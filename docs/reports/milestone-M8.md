# M8 (итог проекта на 2026-10-18)

Все коммиты локальные на ветке `main`; в удалённый репозиторий ничего не отправлялось, внешних действий (VDS, DNS, письма) не было. Скачано только с разрешения владельца: NSIS 3.13, шрифты (Google Fonts, OFL), загрузчик WebView2 (Microsoft) — см. `journal.md`.

## Готово и проверено

- Движок Raven (`5a675b61`) в `engine/`, переименован в Rarus (`rarus`, `RARUS_HOME`, `~/.rarus`); убраны серверный режим аккаунтов, бета-канал, установщики и Docker Raven, `experimental/` и др.
- Вход и баланс через бэкенд alembox (провайдер `rarus`), печать ключа средствами Windows, защита локального сервера, миграция `rarus migrate-raven`.
- Оболочка окна `app/` (окно, трей, один экземпляр, запуск движка, автозапуск).
- Страница: канвас агентов, раздел «Аккаунт» (почта, баланс, пополнение, выход), «уменьшить движение», проверки контраста и внешних ресурсов (M5; `milestone-M5.md`).
- Собранная программа `build\dist\RarusAI` (PyInstaller) и установщик `build\RarusSetup-0.1.0.exe` (NSIS 3.13, 238 084 179 байт, SHA-256 `e8ede176…d160`, со встроенными шрифтами и загрузчиком WebView2): справка, `serve` с `/health` и страницей, окно с экраном входа, вход по запечатанному ключу и баланс в «Аккаунте», чат на подставном API работают; тихая установка, запуск из установленной папки и удаление проверены на итоговом установщике, `/UPDATE` — на предыдущем (скрипт с тех пор не менялся); проверка на секреты проходит (M6; `milestone-M6.md`, «Итоговая сборка 18.10»).
- Живая проверка чата в окне на подставном API alembox (`tools/dev/fake_llm.py`): ответ потоком, автоназвание, остановка, запись файла с карточкой разрешения; найдены и исправлены адрес API при `RARUS_SITE` и «Raven» в карточке (решения 40, 41). Это проверка пути «страница → движок → провайдер», а не настоящей модели.
- Сверка с Raven: RPC, страница, команды, конфигурация, сообщения; матрица приложения А; полный прогон Python и vitest без новых падений (M7; `milestone-M7.md`, `docs/compat/`).

## Не готово

| Что | Почему | Что нужно |
|---|---|---|
| Установщик на чистой машине: без WebView2, интерактивный мастер, три языка на экране, установка поверх запущенной программы | нет чистой машины; тихая установка, удаление и `/UPDATE` проверены только на этой машине | виртуальная машина или второй компьютер |
| Иконка Rarus; кириллица в фирменном шрифте | файла иконки нет; в Instrument Sans нет кириллицы, русский текст рисуется запасным шрифтом | иконка от вас; выбор шрифта с кириллицей, если нужен единый вид |
| Сценарии со своей моделью (`docs/compat/scenarios.md`): 6, 8, 16, 17, 20, 24 не выполнены; 1, 2, 4, 13 выполнены только на сценарной модели (`tools/dev/fake_llm.py`) | нужны живая модель, сеть до alembox и ваш аккаунт | прогон на вашем компьютере |
| Домен Rarus | пока `alembox.com` (ТЗ, раздел 18) | домен и бэкенд под него |
| «Raven» остаётся в мастере `onboard`, в `upgrade`, в именах агентов (`Raven`, `Raven-Code`…), заголовках `X-Raven-*`, имени куки `raven_session` и папке `.raven` в рабочих папках проектов (теневой git движка) | строки мастера — ключи каталога zh, `upgrade` закреплён тестами Raven, имена агентов — идентификаторы в настройках (решения 34, 37) | ваш выбор: переименовать вместе с миграцией настроек или оставить |
| Канвас: метки и фильтр, выбор модели, переключатели инструментов (решение 30) | нужны RPC, которых нет | отдельная задача |
| Размер: около 800 МБ в папке, 227 МБ установщик | `litellm`, `onnxruntime`, `lancedb` целиком | исключения в `rarus.spec` с проверкой запуска |
