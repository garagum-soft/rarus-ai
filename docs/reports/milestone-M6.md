Новая находка в новом файле снова сломает проверку, пока её не разберут.

## Что пошло не так по пути

- `uv pip install ... "app[gui]"` без пути uv понял как пакет `app` из PyPI и поставил чужой `app==0.0.1`. Окружение пересоздано, чужого пакета в нём нет. `build.ps1` ставит по пути (`$root\app[gui]`), то есть работает верно; ту же команду в README стоит запускать только так, как написано (`-e "app[gui]"` с `-e`, из корня репозитория).
- `rarus --help` из собранной программы показывает часть текстов с «Raven» (`status`, `doctor` и др.: ~56 строк в `engine/raven/cli`). Это справка командной строки, не окно и не страница; решение отложено (решение 34 в `decisions-by-executor.md`).

Не проверены: установка, `/UPDATE`, удаление, ярлыки, автозапуск, вопрос об удалении данных.

- Загрузчик WebView2 (`redist\MicrosoftEdgeWebview2Setup.exe`) в пакет не положен: скачивать файл можно только с разрешения владельца. Без него установщик лишь сообщает, что поставить.

- Подписи кода нет.
- Размер: 791 МБ в распакованном виде. Крупнее всего `litellm` (в нём панель прокси со своими страницами), `onnxruntime`, `lancedb`. Урезать можно исключениями в `rarus.spec`, но каждое исключение нужно проверять на запуск; не делалось.
