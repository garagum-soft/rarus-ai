## Что пошло не так по пути

- `uv pip install ... "app[gui]"` без пути uv понял как пакет `app` из PyPI и поставил чужой `app==0.0.1`. Окружение пересоздано, чужого пакета в нём нет. `build.ps1` ставит по пути (`$root\app[gui]`), то есть работает верно; ту же команду в README стоит запускать только так, как написано (`-e "app[gui]"` с `-e`, из корня репозитория).
- `rarus --help` из собранной программы показывал часть текстов с «Raven». 18.10 название заменено в строках, которые печатаются напрямую (решение 34), и в колонках en/zh каталога страницы (решение 37). Остались: мастер `onboard`, `upgrade`, имена агентов (`Raven`, `Raven-Code` и др., это идентификаторы) и заголовки `X-Raven-*`.
- В колесо не вошёл `ui-tui/dist` (сборка предупреждает): команда `rarus tui` в собранной программе не работает. Окно и страница от неё не зависят; судьба `ui-tui/` ждёт решения по Q-12.
