# M5 (канвас агентов, экран «Аккаунт», проверки дизайна): итог — 2026-10-17

## Канвас агентов (ТЗ 10.5–10.6)

Страница «Канвас агентов» зарегистрирована во всех девяти местах страницы модуля (таблица `state/pages.ts`, порядок Escape, строка левой панели со своим значком, шов источников, установка, манифест, эталоны областей и загрузки, офлайн-ответы `org.get`/`org.set`, тесты). Классы и ключи перевода — в пространстве `canvas` (`canvas-*`, `gui.canvas.*`): префикс `cv` уже занят шевроном в `page.css`.

Что работает и проверено **в браузере на настоящем движке** (демо-аккаунт, подставной сервер аккаунта):
- карточка на каждого агента, связь на каждого подчинённого; агенты без строки в иерархии рисуются отдельным рядом;
- перетаскивание карточки на карточку меняет руководителя и записывает `subagents.org` в `config.json` (проверено файлом);
- запрещённый ход (цикл, подчинение себе, неизвестное имя, глубина больше шести) не отправляется и объясняется на русском; отказ движка возвращает прежнюю иерархию;
- «Отменить» (40 шагов, Ctrl+Z), «Вписать», «Раскладка», масштаб колесом и клавишами;
- инспектор: основное (руководитель, отдел, должность, удаление из иерархии с подтверждением в штатном диалоге), промпт сотрудника с историей и откатом, связи;
- экспорт/импорт JSON текстовой панелью; клавиатура: Tab по дереву, стрелки по дереву, Enter, Delete, Esc.

Исправлено по ходу: захват указателя на нажатии уводил `click`/`dblclick` на сцену, инспектор не открывался двойным щелчком — захват теперь с начала перетаскивания; текст отказа перенесён из панели инструментов в свою строку.

Тесты: `graph.test.ts` 31, `store.test.ts` 22, `CanvasPage.test.tsx` 21. Страница рисует пустоту, пока закрыта (`CanvasApp` возвращает `null`): иначе корень канваса, стоящий по алфавиту до «Подключений», вытеснял их из снимка загрузки (см. решение 25); канвас поставлен последним в `MANIFESTS`.

Не сделано из ТЗ 10.6 (решение 30): метки и фильтр, выбор модели через `ModelPicker`, переключатели инструментов и знаний, пять видов связей, режим «Запуск» и «Список», аватар-кадр; частота кадров при 200 карточках и 500 связях не измерялась.
