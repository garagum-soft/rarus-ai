# Упаковка Rarus AI

```
packaging/
  pyinstaller/entry.py      точка входа программы (окно; с --engine — движок)
  pyinstaller/rarus.spec    PyInstaller, режим onedir, один RarusAI.exe
  nsis/rarus.nsi            установщик NSIS 3 (написан по документации NSIS)
  scripts/build.ps1         сборка от страницы до установщика
  scripts/check_build.py    проверка сборки на ключи и внутренние адреса (ТЗ 12.4)
  tests/                    тесты проверки
```

## Что делает `build.ps1`

1. Страница: `npm ci`, `npm run build`, `python build.py` (собирает `dist/index.html`, сверяет снимок загрузки).
2. Колесо движка (`uv build --wheel`): внутри страница, шаблоны и файлы данных, которые кладёт хук hatch.
3. Тесты оболочки и самой проверки сборки — в чистом окружении `build\venv` с установленным колесом.
4. PyInstaller → `build\dist\RarusAI\RarusAI.exe`.
5. `check_build.py` по результату: нет строк, похожих на ключи (`sk-…`, `gsk_`, `AIza…`), `dev-secret`, адресов `192.168.*`, `10.*`, `95.85.125.50`, `127.0.0.1:8115`.
6. Пробный запуск `RarusAI.exe --engine --help`.
7. NSIS → `build\RarusSetup-<версия>.exe` (если `makensis` в `PATH` или в `build\tools\nsis`), повторная проверка установщика.
8. SHA-256 и размер → `build\RarusSetup-<версия>.sha256`.

Скрипт ничего не скачивает, кроме пакетов Python через `uv`. Ключ `-GatesOnly` останавливает его после шага 3 (страница, колесо, тесты): так его вызывает CI. Выпуск по тегу и выкладка на сайт — `docs/release.md`.

## Установщик

* Ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\Rarus AI`, права администратора не нужны.
* Ярлык в меню «Пуск» — всегда; ярлык на рабочем столе и запуск вместе с Windows — по выбору (запуск пишет то же значение реестра, что и переключатель в программе).
* WebView2: если его нет, а в пакете лежит `redist\MicrosoftEdgeWebview2Setup.exe` (файл Microsoft, в репозиторий не входит), он запускается; иначе пользователю сказано, что поставить.
* Режимы: обычный, `/S` (тихий), `/UPDATE` (поверх существующей установки: программа закрывается, выбор прошлой установки сохраняется, данные не трогаются).
* Удаление спрашивает, стереть ли `%USERPROFILE%\.rarus` (по умолчанию нет; тихое удаление данные не трогает).
* Журнал: `%TEMP%\rarus-setup.log`.

## Что не проверено

См. `docs/reports/milestone-M6.md`. Установщик собран NSIS 3.13 и проверен на этой машине (тихая установка, запуск, тихое удаление, `/UPDATE`). Не проверены: чистая виртуальная машина и ветка «WebView2 не найден», интерактивные страницы мастера и надписи на трёх языках на экране, подпись установщика. NSIS в репозиторий не входит: архив `nsis-3.13.zip` распаковывается в `build\tools\nsis`, `build.ps1` находит `makensis` там или в `PATH`.
